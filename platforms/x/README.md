# X（Twitter）长文与短帖（x）

X 同时存在两种形态：短帖（post）与长文（Article）。本文件以 Article 长文为主，短帖规则附后。
核心情境判断：**读者从时间线来，不在"阅读状态"里**——他先看到标题和开头一两行，决定点开；
点开后随时可以退出去看下一条。不用未经证实的推荐、完读率或流量断言。

## 1. 先分形态、入口与关系

```yaml
surface: article / post / thread
entry_route: follow / recommend / share(quote/repost) / search / unknown
reader_relation: 关注者 / 推荐带来的陌生读者 / 转评带来的二手读者 / 混合
```

读者环境多语言、多客户端：简体中文读者可能混在英文时间线里阅读，
关键判断不依赖只有中文语境才成立的典故，必要的英文术语首次出现时给一句解释。

- `follow`：可利用账号共同背景；老读者读过你之前的文章，**跨篇重复同一个开头句式、
  骨架和收尾会被认出来**，见 `../../knowledge/anti_patterns/account_level_monotony.md`。
- `recommend/unknown`：不猜算法；标题与首段必须脱离任何上下文独立成立。
- `share`：转评可能只引用其中一句，关键判断句应能被单独摘出而不失分寸。
- Article 与 post 联动常见：短帖引流、长文承载。短帖约定什么，长文开头就兑现什么，
  不让点进来的读者重新排队。

## 2. 原生基线

```yaml
orality: 5–7
information_density: 6–9
logical_explicitness: 6–9
reader_interaction: 5–8
narrative_presence: 按材料
paragraph_length: 短段为主，单句段允许，但不全文同拍
subheading: 长文按意义单元设置；扫读小标题能还原主线
media: 配图承担真实信息或喘息；媒体数量上限以当前编辑器实测为准，不引用道听途说的数字
```

X Article 不是公众号的换皮：没有时间线之外的"会话框保护"，读者更容易中途离开；
也没有划线评论式的细颗粒互动，**结尾动作主要发生在回复区和转评**。

## 3. 候选结构

- **新闻/争议解读**：事件核心一两句进入 → 先给可核验的判断或拆解框架 → 分层展开
  （事实层 / 机制层 / 误判层）→ 冷水与边界 → 读者可带走的识别方法。
  警惕固定成"日期开头 → 先给答案 → 泼冷水 → 评论区聊聊"的单一模具。
- **工具/复盘**：真实问题场景进入 → 排查与发现 → 修复与验证边界 → 对同类处境读者的
  可迁移判断。验证边界（测了什么、没测什么）是这类内容的核心资产，不是谦辞。
- **概念解释**：一个真实的理解障碍进入 → 先给能用的定义或类比 → 分层校正 → 与读者
  处境的连接。类比要承担理解，不为生动而生动。

选择依据是材料与任务；同一账号近期用过哪个骨架，本身也是选择依据之一。

## 4. 标题—首段—中段—结尾

### 标题与首段

- 时间线里标题和开头一两行就是全部入口：标题给对象与冲突/问题，首段立刻进入事件或判断，
  不用"今天我们来聊聊"式缓冲；
- 不用正文无法兑现的夸张；但也不要把"反标题党"执行成标题没有信息。

### 中段

- 小节承担新增值：新事实、新证据、新分层或新边界；连续两节只证明同一件事就合并；
- 表格只用于真实多维对照；加粗只标真正需要被看见的句子，**全篇加粗格言句保持稀缺，
  且避免与账号近期文章使用同一种强化形式**（见 `../../knowledge/anti_patterns/gold_quote_inflation.md`）；
- 高密度信息后给换气；长文允许叙事段落，但不退化成流水账。

### 结尾

- 完成价值优先：综合判断、可执行自查方法、适用边界，或一个真正开放的问题；
- 回复区邀请要有内容理由（"我漏掉了哪个坑"比"你怎么看"具体），且**不与账号近期文章
  连续使用同一种收尾动作**；
- 数据出处、来源清单适合放在文末分隔线后，这是 X 技术写作的合规资产，不算冗余。

## 5. 事实与来源纪律

- 涉及金额、价格、政策、版本、配额等可核验事实，标明来源与时间截点（"截至 X 日"）；
- 转述社区观点与官方口径分开标记；实测与推断分开标记；
- 不编造 X 的算法、推荐规则与流量规律；功能限制类数字（如媒体数量上限）以当时实测为准并注明日期。

## 6. 短帖（post）附则

- 一条帖子一个核心信息；超过三层逻辑就拆 thread 或写 Article；
- 短帖不做"半截话悬念"引流；承诺与长文开头必须对齐；
- 图片、引用帖承担信息，不是装饰。

## 7. 交付与验收

- 隐去"X"字样后，内容组织仍符合"时间线进入、随时可离开、结尾动作在回复区"的情境；
- 标题与首段能独立成立；中段每节有新增值；结尾动作具体且不重复账号近期收尾；
- 事实有来源与时点；实测与推断分开；没有编造平台规则；
- 与同内容公众号/知乎版本存在实质结构差异，不只是段长与语气词。

## 铁律

X 的读者不是"更没耐心的公众号读者"，而是从信息流里临时停留的人：
开头直接进入价值，中段持续给增量，结尾给可带走的东西——然后让他干净地走。
