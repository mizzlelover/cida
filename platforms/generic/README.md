# 通用适配器（generic）

没有指定平台时的默认呈现规范，适用于一般屏幕阅读场景。

## 参数定位

基于默认 Profile（`STYLE_SYSTEM.md`），呈现层约定：

```
段落：     2–4 句为主，最长不超 6 句；重点判断允许单句成段
小标题：   800 字以上使用；标题说人话（是导航，不是阅兵）
开头：     前 100 字内建立读者与问题的关系
列表：     只在真的并列时使用；并列项超过 5 个考虑分组
加粗：     每屏至多 1–2 处，只给真正的重点
```

## 屏幕阅读原则

- 读者在手机上**扫读**：每段第一句要承担该段的主要信息；
- 段落即换气：段落长度影响阅读心率的感受；
- 关键判断前后留"空地"（短段落、独立行），让它被看见。

## 铁律

平台适配只调整呈现层。**逻辑、判断、证据在任何平台不打折。**
