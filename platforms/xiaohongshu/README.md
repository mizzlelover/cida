# 小红书适配器（xiaohongshu）

## 阅读情境

搜索+推荐双入口；读者带着具体问题来，3 秒内决定留不留。
**对话感最高、切入最快、具体性最强**的平台。

## 参数偏移

```
orality:            +1~2（更高对话感）
intimacy:           +1（但警惕 Fake Intimacy，见反模式库）
concreteness:       显著上调——先给场景、数字、结果
block_length:       短块——视觉上就要轻
entry_speed:        第一句即主题或结果
```

## 专项规则

1. **先给答案/结果，再展开**："三个月把账号做到 X，方法在下面"
   优于娓娓道来；
2. **具体性是硬通货**：数字、步骤、清单、对比——抽象观点必须有实例；
3. **短块与分段节奏**：每块 1–3 行；emoji 作为视觉分隔可少量使用，
   但不承担语义；
4. **语气**：像给一个有具体问题的朋友写答案，不是向广场演讲。

## 反平台腔

警惕："姐妹们"式套近乎（Fake Intimacy）、焦虑贩卖式钩子、
"不看后悔"式恐吓、参数表式排版堆砌。小红书的真实感来自**真实的具体**，
不是语气词。
