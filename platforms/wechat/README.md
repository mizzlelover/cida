# 微信公众号适配器（wechat）

## 阅读情境

手机竖屏、碎片时间、随时退出。读完率是第一约束，但**不靠标题党和
情绪刺激**换取——靠持续的相关性。

## 参数偏移（相对默认 Profile）

```
paragraph_length:   偏短（2–3 句为主）
subheading:         每 300–500 字一个小标题；小标题即内容预告
opening:            更快——前 60 字建立关系
reader_interaction: 6 → 7（更频繁的读者回应）
rhythm:             更多短段落换气
```

## 专项规则

1. **小标题承担导航与"扫读钩子"双重职责**：扫一遍小标题能 reconstruct
   文章主线；
2. **金句位置**：峰值放在小节末与结尾，不放段中（会被扫读跳过）；
3. **段落短而实**：短段落不是切碎，每段仍要完整表意；
4. **结尾**：公众号读者读完率最高损失在中段；结尾要给"读完了值得"的
   收束感（Synthesis / Judgment / Open Question 优先）。

## 反平台腔

警惕：震惊体开头、强行升华、"建议收藏"式乞讨、表情符号滥用、
"深度好文"自封。这些不是适配，是谄媚。
