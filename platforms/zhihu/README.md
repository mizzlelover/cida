# 知乎适配器（zhihu）

## 阅读情境

问题导向：读者因一个问题而来，评判标准是"这个回答有没有真正回答"。
**论证、证据、解释**密度最高的中文大众平台。

## 参数偏移

```
logical_explicitness: 8 → 9
information_density:  上调
evidence:             论断必须有支撑（数据、出处、经验注明）
judgment_strength:    上调——知乎奖励有取舍的真判断
rhetorical_density:   4–5 → 3–4（修辞让步于论证）
```

## 专项规则

1. **正面回答先行**：第一段直接回答问题本身，然后展开；
2. **论证链完整**：主张 → 依据 → 限定 → 反例回应；
3. **经验的合法使用**：个人经验可以用，但要标明是经验（"我自己的经历是……"），
   不冒充普遍规律；
4. **长度自由但不放纵**：长文允许，但每一段都要还在回答那个问题。

## 反平台腔

警惕："谢邀"式自我包装残留、抖机灵式开头抢占注意力、
"人在美国刚下飞机"式资历展示、为反对而反对的标新立异。
知乎的体面来自**把问题当回事**。
