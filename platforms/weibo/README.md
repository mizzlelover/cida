# 微博长文适配器（weibo）

## 阅读情境

注意力最稀缺的环境：信息流中与一切内容竞争。
**结论前置、密度极高、自我完整**。

## 参数偏移

```
entry_speed:        最快——第一句即核心判断或最大信息量
information_density: 最高——每一句都承重（压缩机制见 `knowledge/mechanisms/compression.md`）
structure:          浅结构——长微博用小标题或序号，但层数 ≤ 2
judgment_strength:  上调——立场模糊的内容在微博没有存在理由
```

## 专项规则

1. **第一句决定生死**：把全文最有信息量的判断放第一句；
2. **自我完整**：读者不会点"展开全文"第二次——如果必须展开，
   展开前的部分要已成立；
3. **转发友好**：峰值句要能被单独截图传播而不失真
   （可独立成立，见 Quote-worthiness Filter）；
4. **警惕半截话钓鱼**（"懂的都懂"）——那不是风格，是对读者的怠慢。

## 反平台腔

警惕：震惊体、半截话钓鱼、情绪勒索式结尾（"不转不是……"）。
微博的锋利来自判断，不来自姿态。
