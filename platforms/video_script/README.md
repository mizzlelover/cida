# 视频口播稿适配器（video_script）

## 本质区别

口播稿是**用耳朵读的文本**。评判标准不是"读起来好"，是"念出来顺、
听得懂、记得住"。写着顺口的句子，念着可能憋气；看着清楚的结构，
听着可能迷路。

## 参数偏移

```
orality:            8–9（最高的合法口语度）
sentence_length:    以一口气为上限；顿号处必须能换气
pronounceability:   检查拗口组合（连续仄声、绕口辅音堆叠）
listener_memory:    关键信息重复出现（听众不能倒带）
signposting:        比文章更显性（"先说结论"是口播的合法句式）
```

## 专项规则

1. **朗读测试是强制环节**：每句话默读一遍，喘不上气的拆，
   拗口的改；
2. **数字与专有名词**：第一次出现时要慢、要清；复杂数字换成可感的类比；
3. **听觉回检**："所以刚才说的三件事，核心其实是一件"——
   听觉文本需要更高频的回检收拢；
4. **画面配合**：稿件要为画面留位置（"大家看这个"后必须有真的东西可看）；
5. **结尾**：听觉结尾要干脆——最后一句说完就完，不拖"好了今天就到这里"
   以外的尾巴。

## 边界

口播稿不是逐字聊天稿：语气词折算为语气，不写"呃""那个"；
也不是书面稿朗读版：长定语、嵌套句必须拆掉。
