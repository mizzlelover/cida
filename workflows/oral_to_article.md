# Workflow D：口述 / 访谈 → 高质量文章（oral_to_article）

把语音转录、访谈、随口记录或会议发言整理为可发表文章，保留说话者的人味、判断与独特材料。
目标产物是 Conversation-informed Writing，不是逐字稿，也不是学术论文。
若最终目标是视频或播客脚本，在论证与素材还原后转入相应平台工作流，不强行书面化。

## 0. 核对转录与授权

检查专有名词、数字、成语、引语和可能影响意思的识别结果。无法确认时只做可靠的整理，
保留疑点并说明，不代为补全。固定直接引语、授权范围、隐私和必须保留的事实与限定。

## 1. 先确定用途，再开始删改

按 `workflows/platform_task_contract.md` 明确目标读者、发布场景、内容形态、篇幅与文章用途。
存档、深度学习、快速阅读和平台传播需要不同删留；用途未定前，不大规模删除可能重要的材料。

读取 `knowledge/register/oral-register-behaviors.md`，并按策略从
`repair`、`restatement`、`coherence`、`audience_design`、`information_density` 等节点中取最小集合。
清理话语标记前读 `discourse_markers.md`。

## 2. Preserve Voice & Assets：先标声音与独特材料

先回答：这个人如何思考与说话？直接、谨慎、幽默、爱举例、会自我修正，还是别的特点？
同时标出：

- 只有这个人能提供的经历、现场细节、专业位置和具体观察；
- 能显示判断形成过程的关键转折、犹疑、自我修正与限定；
- 反复出现并承担强调功能的核心词或命题；
- 岔出去但可能有人格、关系或解释价值的支线。

这些内容在压缩前先登记，避免被当成“口语杂质”误删。熟悉这个人的人读完应仍能认出他。

## 3. Remove Speech Noise：只删无功能杂质

删除无功能口头禅、假启动和纯填充停顿。保留承担转折、联合注意、立场、确信度和修复功能的标记。
不要把所有重复、停顿、“其实”“你看”都机械删除；也不要为了人味保留妨碍理解的噪音。

## 4. Recover Argument & Material：还原论证与素材

画出真实结构：

```text
真正的主张 → 支撑事实/经验 → 推理桥 → 限定与反方 → 可执行结论
```

- 合并散落但同向的判断，保留关键推理；
- 区分核心材料、可选支线与无价值离题；
- 标记哪些内容有独特细节，哪些只是通用概括；
- 原材料撑不起目标承诺时，补真实材料、缩小判断或说明限制。

## 5. 候选与价值设计

长文、完整平台稿或结构散乱材料，内部比较 2–3 种组织方式，例如：
按判断组织、按关键经历组织、按读者问题组织。候选必须改变首份材料、信息顺序或价值类型，
不能只是把同一口述顺序稍作清理。

标出入口相关性、首次兑现、后续新增值与完成价值。口述时间顺序不是默认最佳顺序，
但一个关键现场或发现如果最适合建立相关性，可以提到前面，且不改变事实与立场。

## 6. Organize & Compress：组织并压缩

- 按读者需要知道什么的顺序组织，而非按说话先后搬运；
- 删除同义重复，保留一次最有力表达，其余删除或吸收；
- 口语强调的意图不能丢，改用位置、结构、短句或独立段实现；
- 每段承担不同任务，并给读者新增值，不只让文章“看起来更整齐”；
- 重要数字、列举、证据和限定逐项核对，压缩句子不压缩分寸。

## 7. Retain Orality & Add Coherence：保留口语资产，补足书面连贯

保留自然的设问、自我追问、现场细节、语气温度的真实变化。
补齐原口语依赖语境省略的信息，建立段落、指代与衔接。
通常从聊天提升到高质量对话型书面表达，而非学术腔；但具体语域由用途和平台决定。

直接引语与转述分开：引号内原话逐字保留，引号外可调整语序和措辞但不改变原意。
补充事实必须可核实并注明来源，不得写成发言人的原话或现场口径。

## 8. 编辑取舍速查

| 情况 | 处理 |
|---|---|
| 重复框架与口号 | 删无信息框架；保留定调和真实列举功能 |
| 编号与小标题 | 按结构保留或删除；删除后补足自然导航，小标题提供判断或清晰指向 |
| 信息完整的好句 | 不必重写；核对数字、单位、比较基准与限定 |
| 寒暄、重复介绍、离题 | 与用途无关则删；有助于人物、现场或立场则保留 |
| 身份信息 | 首次交代理解所需身份，后文简洁称呼 |
| 其他声音 | 由用途决定；标明来源，与原发言区分 |
| 快讯与短稿 | 先给读者所需结论，保留理解结论必需依据 |
| 导语 | 优先呈现重要判断或真实场景，不照搬发言顺序 |
| 平台稿 | 执行候选比较与价值兑现，不只压缩和换小标题 |

## 9. 双重验收与交付说明

过 `SKILL.md` §7：除事实与声音保真外，检查独特材料是否仍在、目标用途是否完成、
平台版本是否有实质结构变化。任何限定、直接引语或关键证据丢失都返工。

文章后附简短改动说明，概括关键删留、重排或书面化处理，说明原文依据、原因和真实机制边界。
只解释实质取舍，不逐条罗列常规清噪。
