# 诊断方法论（diagnose_text）

一切重写的入口。也单独服务一个任务：**书面文章 → 更自然**（自然化专项）。

## 十项诊断（标准流程）

按顺序完成，每项输出一句话结论 + 证据（摘录原文位置）：

```
1. 原意        作者的核心主张是什么？用一句话复述。
2. 受众        谁在读？他们已知道什么、抵触什么？
3. 文章目标    说服 / 解释 / 记录 / 连接？
4. 当前语域    正式度、口语感各落在 1–10 的哪里？应该落在哪？
5. 语言问题    名词化、翻译腔、长定语、被动堆积、抽象堆叠、虚浮大词
6. 结构问题    结构单调性、比例失衡、顺序违背认知
7. 对话感问题  有没有想象的读者？有没有回应读者下一秒的疑问？
8. 句式节奏    句长分布、停顿、呼吸；是否全文一个强度？
9. 修辞问题    修辞是否承担意义？金句密度？比喻贴切度？
10. 优先级     按 P0–P4 列出本次值得处理的问题清单（允许很短）
```

诊断的原则：

- **诊断必须有证据。** 每条结论附原文位置；没有证据的"感觉不对"降级为假说；
- **允许诊断结论为"无需大改"**——见 `workflows/rewrite_article.md` 的例外条款；
- **不输出"AI味87%"这类百分比。** 只输出具体、可修复的问题。

## 自然化专项：书面 → 更自然

当任务是"把这篇书面文章改得更自然"时，在通用诊断之上重点执行：

### 降低（Lower）

```
nominalization      名词化：把"进行""实现""的……化"还原为动词
academic distance   学术距离："本文旨在""笔者认为"按场景替换或删除
bureaucratic        公文腔："高度重视""扎实推进"类无信息量套话
abstract stacking   抽象堆叠：连续三个以上抽象名词的句子必须落地
over-long           超长依存：一句话超过读者工作记忆的，拆
```

### 提高（Raise）

```
clarity             每句话一眼能懂
concreteness        抽象处补具体：数字、场景、动作
reader orientation  在读者会疑惑的地方，提前半步回应
rhythm              句长随意义呼吸
natural transition  用论证关系转场，减少路牌式过渡
```

### 语域移动的原则

- 语域是**连续空间**，不是"书面/口语"二选一（`knowledge/register/`）；
- 目标通常是**中间语域**：比公文松，比聊天紧；
- 移动语域时，术语与专有表达的准确性不许牺牲——自然化的代价不能是外行化；
- 禁止"纯粹复古化"：目标是现代中文，不是古文腔。

## 输出格式

- 作为重写前置：诊断留在内部，只在改动摘要中体现；
- 用户要求诊断报告时：按十项输出，每项"结论 + 证据 + 建议动作（含优先级）"。
