# Pairwise Evaluation · 成对评测

比绝对评分更重要。操作协议：

## 流程

1. 准备 Version A（原稿或基线）与 Version B（辞达改写）；
2. 评审在**不知道哪版是哪版**的前提下阅读（随机左右）；
3. 逐题选择并给理由：

```
Q1 哪个更容易读？
Q2 哪个更自然？
Q3 哪个更有思想？
Q4 哪个更像真实的人在交流？
Q5 哪个更愿意继续读？
```

4. 记录：每题选择 + 一句话理由；分歧案例必须记录理由全文。

## 判定

- 五题全胜：通过；输掉 Q3（思想）一票否决——立即检查 Preservation Test；
- 评审理由中出现"读起来像 AI""有距离感"等描述时，定位到具体维度
  回填诊断。

## 评审构成

普通读者 / 专业读者 / 内容创作者 / 编辑 四类至少各一；
模型评审可作预筛，但不得单独定论。
