# Human Review · 人工评价

自动指标只作辅助。本目录组织人工评审材料与结论。

## 评审角色

| 角色 | 关注点 |
|---|---|
| 普通读者 | 读得下去吗？懂了吗？愿意继续吗？ |
| 专业读者 | 内容准确吗？判断成立吗？有没有外行化的牺牲？ |
| 内容创作者 | 有个人声音吗？有记忆点吗？值得转发吗？ |
| 编辑 | 结构、节奏、分寸、出版级完成度 |

## 留档格式

```yaml
case_id: ""
reviewers: []        # 角色 + 匿名编号
scores: {}           # 十五维（1–5）+ 总评
verdicts: []         # 每位评审的一句话结论
disputes: []         # 分歧点与处理结论
date: ""
```

## 铁律

- 评审必须基于文本本身，不知道产出版本身份（盲评）；
- 分歧不强行调和，记录在案；
- 评审结论回流入 `knowledge/practitioner_hypotheses/` 或反模式库。
