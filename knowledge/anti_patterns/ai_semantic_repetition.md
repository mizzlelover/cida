# AI Semantic Repetition · 语义重复

```yaml
name: AI Semantic Repetition
aka: 同义反复 / 换着说法说三遍
```

## symptom

同一层意思在相邻位置出现两次以上，每次换几个近义词：

- "这不仅提升了效率，而且提高了效能，还优化了效果。"
- 段首说一遍，段中展开的还是它，段尾再总结一遍——信息零增量。

## example

```
数字化转型非常重要。它对企业至关重要。在当今时代，没有数字化
转型企业将难以生存。因此，数字化转型的重要性不言而喻。
```

四句一个信息点：重要。至于为什么重要、对谁重要、怎么重要——缺席。

## why_it_hurts

读者的时间被重复征收，信任被稀释：作者没有更多东西可说了。
语义重复常与 **Empty Summary**（空总结）共生：因为没内容，所以反复宣布有内容。

## possible_mechanism

内容不足时用复述凑篇幅；或生成时的"段落完整性"强迫——每段都要
自给自足地起承转合，于是观点在每段首尾各回声一次。

## repair

1. 同义句聚类，保留表达最有力的一句；
2. 被删位置用**增量信息**填充：为什么、多严重、怎么办、一个例子；
3. 若填充不出增量，说明该段本来就不该存在——整段删（Delete before Rewrite）。

## exceptions

- 关键结论在开头与结尾各出现一次（首尾呼应）是合法的强调，前提是结尾有推进；
- 口语中的强调式重复（说三遍）在口播稿中部分保留，转成文字时改为位置强调。
