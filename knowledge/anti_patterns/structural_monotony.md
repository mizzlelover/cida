# Structural Monotony · 结构单调性

```yaml
name: Structural Monotony
aka: 被误称为"AI结构"的真问题
```

## symptom

- 每一节长度几乎完全一样；
- 每段都先结论后解释，全篇同一拍子；
- 每个一级标题都是同一语法结构（都是动宾、都是四字）；
- 任何话题都拆成三点，三点内部再拆三点。

## example

```
一、XX的重要性。（200字）
二、XX的现状分析。（200字）
三、XX的未来展望。（200字）
——每节内部都是"总起句+三个短句+总结句"。
```

## why_it_hurts

读者对结构形成预期后，预期本身变成噪音：看一段就知道所有段的写法，
注意力的"地形"被抹平，重点无处安放。**结构清晰不是罪——机械才是。**
真正的问题不是"有结构"，而是结构不再为内容服务，内容反过来削足适履填结构。

## possible_mechanism

模板化生成/写作时，"完整、对称、均匀"是最省力的默认解；
人类作者在对主题缺乏判断优先级时也会退守均匀结构（没有取舍，只好均分）。

## repair

1. 按内容重要性重新分配笔墨：重要的部分写长、写细；
2. 让各节的写法随内容变化：叙事的部分用叙事，分析的部分用分析；
3. 合并琐碎的并列点（三个小点合成一段流畅论述）；
4. 标题允许长短不一、句式不一——标题是导航，不是阅兵。

## exceptions

- 法律条文、规范文档、清单式教程**要求**均匀结构，不适用本条；
- 有意为之的对称（回环、对照修辞）是修辞，不是病灶。
