# Template Transition · 模板过渡

```yaml
name: Template Transition
aka: 路牌式过渡 / Over-signposting
```

## symptom

段落之间靠"路牌"而不是论证关系衔接：

- "接下来我们来看……""下面让我们……""值得注意的是……"高密度出现；
- 每段开头都有过渡词，全文连接词过密；
- 过渡词与内容脱节（说了"然而"却没有转折）。

## why_it_hurts

路牌太多的路反而难走：读者的注意力被过渡本身消耗，论证线反而看不清。
**好的过渡发生在语义层**：上一段的结论天然引出下一段的问题。

## possible_mechanism

写作时缺乏对论证流的整体把握，只好在每段接缝处打补丁；
或把"衔接"误解为"必须有衔接词"。

## repair

1. 先删后看：删掉全部过渡词通读，哪些地方真的断裂了？只在断裂处补；
2. 优先用语义衔接：承接上段的关键词、指代、话题链
   （见 `../mechanisms/topic_progression.md`）；
3. 必须用标记时选"轻"的：一个"但"胜过"然而值得我们深思的是"。

## exceptions

- 长文（3000 字以上）的章节级过渡允许更显性的导航；
- 口播稿中过渡标记密度天然更高（听众不能回看）；
- 教程类文本的步骤标记（"第一步"）是功能性的，不是模板。
