# Abstract Inflation · 抽象通胀

```yaml
name: Abstract Inflation
aka: 大词堆叠 / 概念空转
```

## symptom

- 连续多个抽象名词："赋能、抓手、闭环、生态、体系、维度"轮番登场；
- 一句话里没有一个看得见摸得着的东西；
- 用更大的词解释大词（"数字化转型是数字化的转型"式循环）。

## example

```
通过构建全链路数字化赋能体系，打造多维度业务闭环生态，
实现组织效能的系统性跃升。
```

——读完后，读者不知道这家公司在做什么。

## why_it_hurts

抽象词的理解成本由读者支付。堆叠抽象 = 把思考的活儿外包给读者。
抽象通胀常与 **Fake Depth** 共生：用术语的海拔冒充思想的高度。

## possible_mechanism

商业文体的"专业感"焦虑；作者自己也没想清楚（抽象是模糊的保护色）；
生成式文本的"高层级词汇偏好"。

## repair

1. 逐句问：这句话能用一个人、一个动作、一个数字落地吗？能就落地；
2. 抽象词配额制：一段至多一个新概念词，且必须紧跟解释或例子；
3. 保留必要的术语（受众是专业人士时），但术语密度与读者水平匹配
   （见 `../mechanisms/explanation.md`）。

## exceptions

- 学术写作、政策文件有自身的抽象惯例与精确性要求，按语域处理；
- 高度抽象的概念讨论（哲学、理论）不适用"每句都落地"，但仍要求举例。

## 真实样本验证（2026-09-12）

- 真实外部负例 `corpus/contrast/pr-softad-real.yaml`：PR 软文以"设备台账数字化、
  维保流程标准化、故障预警智能化"式四字格三连与单句七动宾短语连排堆叠——检验法：
  把每个"-化"短语还原为具体动作，还原不出即为失效。
- 语境边界：政策原文（如"七大专项行动、21条核心举措"）中的凝缩四字格承担真实概括
  功能，不构成反模式——判据是**能否还原为具体动作与行为者**，不是词形本身。
