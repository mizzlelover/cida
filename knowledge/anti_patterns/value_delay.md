# Value Delay · 价值拖欠与空头约定

## symptom

开头只有背景、姿态、预告或刺激，正文直到很后面才给第一次真实获得；
或标题和开头作出强烈承诺，中段却反复同义重述，让读者等待最终答案。
另一种形态是每段末尾都说“下一点更重要”，但下一段没有实质增量。

## why_it_hurts

读者先付出时间，文本却没有及时证明值得继续。即使最后有好结论，
前中段的低兑现也会放大阅读成本；如果承诺超出材料，还会损害可信度。

## possible_mechanism

把悬念误解为延迟价值，把结构完整误解为读者愿意等待，
或先写刺激入口，再让正文承担无法兑现的承诺。
关联 `../mechanisms/value_promise.md` 与 `../mechanisms/value_payoff.md`。

## repair

- 标出入口约定、首次兑现、每个主要单元的新增值与完成价值；
- 前段只有预告时，把不妨碍理解的真实判断、证据、方法或场景前移；
- 连续单元价值相同时合并、删除或补入不同认知任务；
- 正文撑不住承诺时降低承诺或补真实材料，不继续加强钩子；
- 结尾才首次出现核心价值时重排，不在开头重复“后面会讲”。

## exceptions

文学叙事、深度报道、复杂论证和探索性播客可以延迟完整答案。
只要场景、人物、证据、问题或理解过程本身持续提供价值，就不算价值拖欠。
本反模式针对无获得的等待，不针对任何特定的慢叙事或开头形式。
