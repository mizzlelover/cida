# Gold-quote Inflation · 金句通胀

```yaml
name: Gold-quote Inflation
aka: 强行升华 / 每段一个金句
```

## symptom

- 每段结尾都是"这，就是 XX"式收束；
- 全文都是"漂亮话"，读完却记不住任何一句；
- 知识服务腔收尾："愿你被这个世界温柔以待""时间会给你答案"；
- 没有判断的地方也要升华（把产品介绍升华成人生哲理）。

## why_it_hurts

金句的价值来自稀缺。当每句话都想成为金句，等于全文没有金句——
读者的"峰值记忆"被摊平，还产生被讨好、被煽动的戒备。
修辞过产的本质，是用形式的勤奋掩盖判断的缺席。

## possible_mechanism

自媒体流量逻辑训练出的"每段都要有传播点"；对"好文章=金句多"的误解；
以及生成式文本的"升华偏置"——结尾倾向于拔高。

## repair

1. 用 Quote-worthiness Filter 过滤全文"漂亮句"
   （见 `../mechanisms/rhetorical_peak.md`）：是核心判断吗？压缩了前文吗？
   有新视角吗？能独立成立吗？与上下文呼应吗？
2. 保留 1–3 个真峰值，放在论证线上；
3. 其余漂亮句降级为普通表达，或删除；
4. 结尾改从 Synthesis/Judgment/Open Question 等方式中选一种真实的收束。

## exceptions

- 演讲稿（SPEECH）的峰值配额高于文章，但仍受稀缺性约束；
- 用户明确要求"金句体"（如海报文案）时按任务执行，并提示风险。

## 真实样本验证（2026-09-12）

- 真实外部负例 `corpus/contrast/gold-quote-listicle-real.yaml`：内容农场语录合辑
  十条十条金句、零语境零具体经验、对仗模板四连发（"不能X但可以Y"）、"早安/晚安"
  机械收尾——Quote-worthiness Filter 五问全部落空：非核心判断（无上下文可压缩）、
  无新视角、不与上下文呼应。
- 反例校准（≠禁词表）：格言集/日签类产品的体裁原罪在读者成本，不在线条本身；
  正面对照见和菜头《抒情的基础》结尾"省脑子就会导致费钱，句号。"——同样短促有力，
  但压缩了前文全部论证，五问全过。
