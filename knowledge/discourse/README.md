# 汉语篇章与语篇研究要点（discourse）

辞达的篇章观：**文章是一连串话题与衔接的编织物，不是句子的简单堆叠。**

## 核心命题

1. **话题链（Topic Chain）。** 中文的篇章推进大量依靠话题链：
   一个话题领起一串小句，主语可以承前省略。重写时话题链的断裂
   （主语无谓跳跃）是"读着乱"的常见根源。见 `../mechanisms/topic_progression.md`。
2. **衔接 ≠ 连接词。** 衔接手段有层级：重复/指代/省略（词汇语法层）、
   逻辑关系（语义层）、连接词（标记层）。优先用深层手段，
   连接词是最后的选择。见 `../anti_patterns/template_transition.md`。
3. **Cohesion 是皮，Coherence 是骨。** 表面衔接再多，语义不连贯仍失败；
   反过来，语义连贯时表面标记可以很少——好文章常常"无词自通"。
4. **前景与后景。** 主线推进（前景）与背景信息必须分层；
   背景信息侵入前景是"读着累"的常见原因。
5. **Metadiscourse 的剂量。** "本文将讨论""综上所述"类元话语是导航，
   剂量过高变成官僚主义，过低读者迷路。

## 操作清单（重写时的篇章检查）

```
□ 画出每段的中心话题，检查话题链是否连续
□ 检查段间关系：递进/转折/并列/补充——读者两秒内能识别吗？
□ 背景信息是否侵占了主线段落？
□ 指代是否清晰（"这""它"指向唯一吗）？
□ 元话语密度是否合适？
```
