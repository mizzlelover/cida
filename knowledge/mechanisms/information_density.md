# Information Density · 信息密度

```yaml
id: mech.information_density
name: 信息密度
function: 控制单位阅读努力中真正抵达的判断与证据
confidence: validated
```

## definition

信息密度不是字数越多越好，而是新信息、判断、例证和必要限制的有效比例。

## mechanism

区分承重成分、关系成分和噪声；在高密度段落增加换气和回检，在低密度段落不靠修辞填空。

## realizations

博客用段落和小标题分层；口播用停顿和重复承重词；正式文本用事项和责任边界。

## boundary_conditions

共情、叙事和复杂推理允许较低表层密度；统计只能提示异常，不能给统一字数目标。

## overuse_risk

追求密度会删掉证据和人际功能，变成电报腔。

## repair_strategy

逐句问删去会损失什么；删无损句，保留限定、证据和关系动作。
