# Topic Return · 话题回环

```yaml
id: mech.topic_return
name: 话题回环
function: 让暂时离题的材料重新服务主线
confidence: validated
```

## definition

回环给读者一个信号：刚才的故事、例子或旁支没有被遗弃，它改变了主线的理解。

## mechanism

离题前暗示关系，旁支中提供新信息，回来时明确吸收或排除；只回到主线，不强行回到原句。

## realizations

‘说回最初的问题’可以使用但不必固定；文章用一个前文意象回收；播客由主持复述收拢。

## boundary_conditions

真正的新主题应分节或另起文本，不用回环掩盖结构失控。

## overuse_risk

频繁回环会让文本显得设计过度。

## repair_strategy

画出话题链，只保留能改变主判断的旁支，其余删除。
