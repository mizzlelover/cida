# Reframing · 重框

```yaml
id: mech.reframing
name: 重框
function: 改变问题的观察单位而不是回避原问题
confidence: validated
```

## definition

重框把‘个人失败’改看成‘流程约束’，或把‘岗位替代’改看成‘任务重组’，但必须回应原问题而不能偷换。

## mechanism

承认原框架能解释的部分，指出其遗漏，再提出更能解释材料的新框架；新框架必须带来不同的行动或判断。

## realizations

评论中从情绪词转到机制；访谈中从个人故事转到制度条件；文章中用‘如果只看这一层’承接。

## boundary_conditions

重框不能抹掉责任、伤害或事实；涉及权力不对等时要避免把受害者责任化。

## overuse_risk

凡事都上升为系统问题会稀释具体责任。

## repair_strategy

同时写出个体层、关系层和制度层中至少一个被保留的具体事实。

- **评论体补充样本（2026-09-16）**：《新闻1+1》20090616（`corpus.commentary.bai-20090616-death-penalty`，ANNOTATED，央视网实录直读）——**两处重框承担全部推进**：①民调数字从约 70% 掉到 50% 几，观察员不归因于民众素质，而归因于**提问措辞诱发的感性**（"这里本身有一句话叫罪大恶极，民愤极大，于是调动的是他内心感性的这种因素"）；②"注射是否削弱震慑"被重框为"**对旁观者的附加刑罚**"——"其实是给社会附加的一种刑罚，即使是给没有任何犯罪的人，都会变成一种惩罚"。《新闻1+1》20081009（`corpus.commentary.bai-20081009-nobel-science`，ANNOTATED）另给一例"**捅破窗户纸**"式重框：不否认"不该套近乎"，而把争论换到"我们其实在乎诺贝尔奖"。三例共同点：**驳的是框架与观察单位，不是对方的正当性**。
- **同语域第二篇（2026-09-16 补，补第二位表达者）**：王毅联合国人权理事会讲话（`corpus.speeches.wang-20240226-un-human-rights`，ANNOTATED）——"'有选择的多边主义'不应成为我们的选择"：**引用对方提法并当场拒绝**，把"哪些多边主义可接受"这一争论换到**己方判据**上（规则一旦确定，大家都要有效遵循）；改变的是**观察单位（谁在挑选规则）**，而非否认对方存在。
- **第三类切入动作"换归属"（2026-09-17 补）**：黄执中（`corpus.podcasts.ted-2017-debate-thinking`，ANNOTATED，TED 中文稿逐段深读）——业务员问"客户不信任我怎么办"，讲者把这一问题的**归属逐次移动**：**我的问题 → 客户的问题**（"王先生，您对我的不信任这个问题您要重视，因为它让我们增加很大成本"）**→ 公司的问题**（"我穿公司制服出去客户都不信任我，公司该怎么办"），并明说"这是谁的问题并不是固定的，是随着你观察视角的不同，它是可以移动的"。与前三例并列，构成本节**第四种切入动作**（前三：换称谓／换归因／换判据）；边界：**移动归属不改变事实责任**，迁移到真实纠纷时须保留责任边界（见本页 `boundary_conditions`）。详档 `corpus/annotations/podcasts-deepread-20260917.md`。

- 状态：`validated`（2026-09-16 登记）。本批补入**第二位表达者**（此前三例同属白岩松，实际仅 1 位表达者）。

- 跨来源比较——**"改变观察单位而不回避原问题"跨语域收敛，差异在切入动作**：
  1. **换称谓**（白岩松 20130730，电子媒体）：先复述媒体称谓"极端的维权"，再判定"这个说法完全可以商榷，这是一种极端的暴力"——**先进入对方语词 → 判定不成立 → 替换称谓**；
  2. **换归因**（白岩松 20090616，评论体）：民调从约 70% 掉到 50% 几，不归因于民众素质，而归因于**提问措辞诱发的感性**；
  3. **换单位**（同篇）：把"注射是否削弱震慑"转为"**对旁观者的附加刑罚**"；
  4. **换判据**（王毅，官方致辞）：引"'有选择的多边主义'"并当场拒绝，把争论换到"规则须普遍遵循"上。
  四者共同落点＝本页 mechanism「承认原框架能解释的部分，指出其遗漏」与 definition「必须回应原问题而不能偷换」；差异在**切入动作**（换称谓／换归因／换单位／换判据）。
- 边界：① 白岩松 20130730 为**直播速记稿（含转写错字）**，只支撑结构层；② 样本**集中于同一表达者**（3:1），故本判定**不主张"跨表达者广泛性"**，只主张机制成立；③ `boundary_conditions`（不得抹掉责任、不得把受害者责任化）**未做真实反例抽样**。
