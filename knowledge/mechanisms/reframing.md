# Reframing · 重框

```yaml
id: mech.reframing
name: 重框
function: 改变问题的观察单位而不是回避原问题
confidence: contextual
```

## definition

重框把‘个人失败’改看成‘流程约束’，或把‘岗位替代’改看成‘任务重组’，但必须回应原问题而不能偷换。

## mechanism

承认原框架能解释的部分，指出其遗漏，再提出更能解释材料的新框架；新框架必须带来不同的行动或判断。

## realizations

评论中从情绪词转到机制；访谈中从个人故事转到制度条件；文章中用‘如果只看这一层’承接。

## boundary_conditions

重框不能抹掉责任、伤害或事实；涉及权力不对等时要避免把受害者责任化。

## overuse_risk

凡事都上升为系统问题会稀释具体责任。

## repair_strategy

同时写出个体层、关系层和制度层中至少一个被保留的具体事实。
