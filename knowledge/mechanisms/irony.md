# Irony · 反讽

```yaml

name: 反讽

confidence: validated
```

## definition

反讽不是把话反着说，而是让读者同时看到字面说法、现实证据和两者的落差。
落差必须可由语境和事实回收，不能依赖读者猜作者心情。

## mechanism

表层命题→语境提示→证据落差→明确回扣。文本越短、受众越陌生，越需要显式标出反讽的目标
与边界。

**判定补充（2026-09-16 由语料核对得出）**：四步中**最容易缺的是第四步**。已核验样本的共同点是
**回扣句在文本内可见**（如"但就怕不是""你觉得会吗？""我不公报私仇我还给谁报仇啊？"）；
**没有回扣句**的候选即使前三步齐备，也只登记为弱形态、不升级——回扣不是修辞尾巴，而是判定条件。

## realizations

评论可用引号、并置事实或克制的反问揭示口号与结果的差异；访谈中先复述对方命题，再让
后续事实显出不一致，避免凭语气暗示。

**2026-09-16 语料补入后已核验的两类实现**（均出自 ANNOTATED 条目，见 `sources`）：

1. **按对方说法反向推演 + 一句回扣**（评论语域·白岩松 2019）：先把对方的说法原样摆出并按之推演
   （"要是真建这样的一个养老院……那真有点感动中国的意思了"），再用一句"但就怕不是"把落差收束；
   落差的事实由同页数字与时间线承担。
2. **讥讽式认同**（访谈语域·崔永元 2018）：把对方的指控**原样承接**（"对，说得特别对，就是"），
   随即用一句反问把标签收编为正当理由（"我不公报私仇我还给谁报仇啊？"），
   并拒绝对方附赠的正面命名（"别天天推我当什么民族脊梁、人民英雄"）。
   这一形态**表面像"把话反着说"，但落点仍是"让读者同时看到字面说法与事实"**，故仍属本机制。

## boundary_conditions

涉及安全、医疗、法律和跨文化传播时，不把反讽当作唯一的事实表达；没有共同语境就改用直接判断。

**正例（2026-09-16 补）**：`corpus.commentary.bai-20190421-yuanfu` 是这条的**服从实例**——
反讽只出现在评论段情绪落点，全部事实（亩数分项、房间用途、审批时间线、三次处罚）**先以直陈给出**，
未决处写"目前无法给出答案"，即**反讽不承担举证责任**。

## overuse_risk

反讽密集会制造犬儒距离、误读和对人的攻击，也会把作者的真实立场藏掉。

**靶子选择（2026-09-16 补）**：已核验样本的靶子都是**说法与行为**（"养老院"的用途说法、
条款预设的动机），涉及未证实的个人关系时作者显式留边界（"如果这个事实要是是真的话"）。
把靶子换成人身，正是本风险的具体形态。

## repair_strategy

问“读者是否能指出反讽针对的命题和证据”；若不能，改成直接陈述、对照或让步，不靠语气赌理解。

- **跨来源比较（收敛点与差异）**：
  1. **收敛点一：四步中"回扣"必在文本内可见**——三条样本各有独立回扣句，且都不依赖语气推断；
  2. **收敛点二：落差由可核对的事实承担**——袁府条用亩数分项与审批时间线、公务员兼职条用清理数据
     与"屡禁不止"、崔永元条用同一页的股价数据；**没有一条把落差留给读者的语感**；
  3. **差异：表层命题的来源不同**——白岩松两例的表层命题是**制度措辞与项目说法**（"不得领取报酬"
     "是养老院"）；崔永元例的表层命题是**对己的指控**（"公报私仇"），故形态从"反向推演"变为"讥讽式认同"。
     二者共用同一判定四步，说明本机制**不依赖表层的来源类型**。
- **边界（如实登记）**：
  1. **样本量小**（3 条／2 位表达者，仅评论与访谈两语域），**不主张跨语域普遍性**；
  2. **未做反例抽样**——`overuse_risk` 所述"犬儒距离、对人的攻击"**无真实负例样本**；
  3. `boundary_conditions` 中"跨文化传播场景改用直接判断"一条**无样本验证**（已核验样本均为国内公共议题）；
