# Confidence · 确信度

```yaml
id: mech.confidence
name: 确信度分级
function: 使语言强度与证据等级匹配
confidence: contextual
```

## definition

确信度管理断言、判断、倾向和猜想之间的梯度，避免事实不足时写成确定结论。

## mechanism

为主张标注证据等级和反证可能，再选动词、情态和结尾方式；高置信度不等于强修辞。

## realizations

研究笔记显式写 confidence；文章用‘可以确认/更倾向于/尚不能判断’；口播用复述校正。

## boundary_conditions

法律、医疗和公共政策文本要遵循正式证据和责任标准，不能由语言强弱自行升级。

## overuse_risk

把所有结论都降为‘值得关注’会回避判断。

## repair_strategy

把低置信度原因写出来，能补证据就补，不能补就保留边界而不是堆模糊词。
