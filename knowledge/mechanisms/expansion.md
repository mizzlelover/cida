# Expansion · 解释展开

```yaml
id: mech.expansion
name: 解释展开
function: 在不稀释主判断的前提下补足必要的背景、步骤或例证
confidence: validated
```

## definition

展开是把读者已经看见、但还不能检验或使用的判断，推进到足够的背景、过程和例证。
它不是把每个细节都写出来，而是补齐理解所必需的那一层。

## mechanism

判断→缺口→最小背景→过程或例证→回到判断。展开的单位由读者的未知和任务决定，
不是由篇幅或固定段数决定。

## realizations

解释文先给读者一个熟悉锚点，再补术语和步骤；评论文只展开会改变判断的事实；口述成文把
现场跳跃补成可追踪的因果链。

## boundary_conditions

如果新增材料不改变理解、行动或判断，就不应展开；专业读者已知的背景可压缩为一句边界。

## overuse_risk

把背景资料全盘搬入会遮住主线，形成百科式铺陈、假完整和信息疲劳。

## repair_strategy

逐段标出读者需要回答的一个问题，只保留直接回答该问题的背景、步骤或例证，其余移入备注或删除。
