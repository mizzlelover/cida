# Softening · 缓和

```yaml
id: mech.softening
name: 缓和
function: 调节异议、请求和不确定判断的社会距离
confidence: validated
```

## definition

缓和让表达不把必要的判断变成人身对抗，同时不把结论稀释成无信息的‘可能也许’。

## mechanism

先判断对方关系和权力差，再选择限定词、主体转移或证据先行；缓和后必须仍能看出作者承担什么判断。

## realizations

‘更稳妥的做法是’‘至少在这个场景里’；口播用停顿和语气；正式文本用适用条件。

## boundary_conditions

安全、法律、医疗和责任事项不能用礼貌缓和掩盖明确警示。

## overuse_risk

每句都加‘可能’会逃避判断。

## repair_strategy

给每个缓和词标注它限定的是证据、范围还是态度；无法说明功能的删掉。

## 跨来源验证（§121）

- 状态：`validated`（2026-09-16 登记）。
- 依据（§121 二选一取后者）：**理论**＝何自然语用学、冯胜利语体语法；**语料样本**＝王辰（答问体）、周轶君（演讲体）、**董卿（点评体，2026-09-17 补）**，**3 位表达者、3 语域**。
- 跨来源比较——**"缓和的是适用范围，不是判断本身"跨语域收敛，差异在缓和对象**：
  1. **限定适用范围**（王辰，答问体）：先"这些担心有一定的道理"，再限定（轻症患者的两个特点）；对拐点则明确"无法预测"并列出四条件——缓和的**是"担忧的适用范围"**；
  2. **给己方叙述加反向可能**（周轶君，演讲体）："当然你不排除有时候我发现在他们身上也会有一些冲动或者是那种荣誉感而已"，避免把异国青年理想化；
  3. **移交受众评判权**（董卿，点评体）："好的我就不说了，因为你们的好观众一定都看得很明白"——把对"优点"的判断**交由受众**，自己只谈可改进处，**缓和的对象是"评价权"而非事实**。
  三者共同落点＝本节要求「缓和后必须仍能看出作者承担什么判断」（见 boundary_conditions 与 overuse_risk）；差异在**缓和对象**（对方的担忧范围／己方的叙述／受众的评判权）。
- 边界（重要）：① 三例均**未**把缓和用于安全或医疗警示——`boundary_conditions` 明令此类事项不得用礼貌缓和掩盖明确警示，答问体在"当天隔离""一定要临床实验"等处**保持直陈**，可作正面印证；② 副语言层未听校；③ `overuse_risk`（把所有异议都包装成温和共识）**未做真实负例抽样**。
