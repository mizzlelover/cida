# Metaphor & Analogy · 比喻系统

```yaml
id: mech.metaphor_analogy
name: 比喻与类比
function: 用熟悉的事物降低陌生事物的理解成本
confidence: validated
```

## definition

比喻必须承担功能，三条出路，至少居其一：

```
help understanding   帮助理解（解释型比喻）
help memory          帮助记忆（锚定型比喻）
help emotion         帮助情感（共鸣型比喻）
```

一条都不占的比喻是装饰品。**禁止为了文采强行比喻。**

## 质量维度

```
Analogy Fit        贴切度：喻体与本体在关键属性上真的相似吗？
Metaphor Distance  距离感：太远读者接不住，太近没有新信息
Novelty            新鲜度："像一把双刃剑"已死——陈喻不产生理解增量
Clarity            清晰度：比喻本身比本体更难懂 = 负资产
Cultural Fit       文化贴合：目标读者熟悉这个喻体吗？
```

## 操作规范

1. 解释复杂概念时，**先想直白解释够不够**，够了就不用比喻；
2. 必须用比喻时，从**目标读者的生活域**取材，不从作者的炫技域取材；
3. 一个比喻只用一次；同一个喻体在全文中要保持一致；
4. 比喻之后必须回到本体：比喻是桥，不是家。

## examples

- 好（解释型）：向非技术读者解释缓存——"就像把常用的调料放在灶台边，
  而不是每道菜都跑一趟储藏室。"贴切、熟悉、帮助理解。
- 坏（装饰型）："时间如白驹过隙，转瞬即逝。"——无理解增量，无情感增量，陈喻。

## mechanism

用熟悉源域的结构去检索陌生目标域：理解成本从"现场建构"降到"调用已有模型"
（概念隐喻：人靠源域理解目标域，`src.intl.lakoff-metaphors`，review_only）。
故本页两条判据是机制成立的条件而非审美偏好——**Analogy Fit** 决定映射是否成立，
**Metaphor Distance** 决定映射带来多少新信息；`definition` 的三条功能路径
（帮助理解／记忆／情感）是这次映射的**收益检验**，一条都不占即映射无收益。

机制的完成条件是**回到本体**（本页「操作规范」第 4 条）：比喻只承担过河，
不承担结论——本页 `## realizations` 与 `## sources` 所列语域样本，
都把条件、制度或比例留在比喻之外。

## realizations

- **written**：意象与常识类比承担解释与锚定（"就像把常用的调料放在灶台边"；
  类比写作的书面分析见 `corpus/blogs/` 刘未鹏《Mind Hacks》），喻体只出现一次
  并在后文保持一致；
- **spoken**：现场比喻**随即被条件兑现**——王辰称方舱是"诺亚方舟上的一个舱位"，
  紧跟资源、速度、收治层级三项条件（`corpus.interviews.bai-20200205-wangchen-cabin`，ANNOTATED）；
  周轶君的**否定式喻体**"外面的世界不仅仅是一个非常大的免税商店"用边界代替描述
  （`corpus.podcasts.ted-zhouyijun-2017`，ANNOTATED）；陈晓卿以比例锚定与
  "味觉信息茧房"承担概念，并**借导演之口当场自检喻体**
  （`corpus.podcasts.ted-chenxiaoqing-2020`，ANNOTATED）；
  **2026-09-17 追加**：郝广才的"翅膀"是**同一喻体复现而功能递进**（成长空间 → 裹小脚式的不可逆损害 →
  纪伯伦"弓与箭"的父母角色），与本节"喻体只出现一次并在后文保持一致"的书面规范形成对照；
  黄执中以"画水瓶／画龙舟的角度"把抽象的"观点"具象化，并在故事后**主动反推喻体的来源**
  （迎面角度不可能亲见，是想象），避免把喻体读成天才论
  （`corpus.podcasts.ted-haoguangtsai-2015`、`corpus.podcasts.ted-2017-debate-thinking`，均 ANNOTATED）；
- **formal**：官方致辞以意象承担判断、以**成对隐喻**界定立场——"寒冬阻挡不了春天的脚步，
  黑夜遮蔽不住黎明的曙光"、"56 个民族像石榴籽一样紧紧抱在一起"、应为"平台"而非"战场"
  （`corpus.speeches.xi-20210125-davos-agenda`、`corpus.speeches.wang-20240226-un-human-rights`，均 ANNOTATED）；
  **2026-09-17 追加**：李强·达沃斯 2024 以**全景视角类比**承担"如何看待中国经济"的方法
  （看阿尔卑斯山须"把视野放宽、把目光投远"），并以**结构喻**说明产业链
  （"血管系统"／"梗阻""断点"）；王毅·安理会 2023 的危机意象（"加沙地带没有防火墙"、
  "吞噬整个地区的浩劫"）**集中于判断段**，每处意象之前先给事实或条款
  （`corpus.speeches.li-20240116-davos`、`corpus.speeches.wang-20231129-unsc-gaza`，均 ANNOTATED）；
- **informal**：**无专门语料样本**——按 §121 纪律不据此主张，不以推测补齐。

## boundary_conditions

- 科技与财经写作中，错误类比比没有类比更糟（Analogy Fit 优先）；
- 抒情文本可放宽 Novelty 要求，但不能突破 Clarity 底线；
- 比喻密度受 Rhetorical Density 参数约束，峰值位置的比喻待遇最高。

## repair_strategy

文本"花哨但空洞"：列出全部比喻，逐一过三功能检验，装饰品全删，
留下的检查 Fit 与 Distance。文本"正确但难懂"：为最抽象的概念配一个
读者生活域的类比。

## overuse_risk

陈喻、跨域过远的喻体和连续比喻会增加理解成本，把解释变成装饰。

- 状态：`validated`（2026-09-16 登记）。

- 跨来源比较——**比喻的"收尾动作"不同型，但都回归本体**：
  1. 王辰（答问体）：**条件兑现**——"诺亚方舟上的一个舱位"后立即给资源、速度、层级三项条件；
  2. 周轶君（演讲体）：**否定式划界**——"外面的世界不仅仅是一个非常大的免税商店"；
  3. 陈晓卿（演讲体）：**自设反驳**——恋爱之喻后被反问解构。
  三者共同落点即本页操作规范第 4 条「比喻是桥，不是家」：无一例让比喻独立承担结论；差异在**回本体的方式**（兑现条件／划界／自嘲解构）。
- 边界：样本全为口语语域（两位 `scripted` 台本）；`examples` 中依存的书面正例（缓存／调料）仍未经逐篇语料验证；故 `validated` 指**机制与三功能检验成立**，不给出各文体的比喻密度数值，`boundary_conditions`（错误类比比没有类比更糟）继续适用。
