# Summary · 阶段收拢

```yaml
id: mech.summary
name: 阶段收拢
function: 在认知节点把已知信息压成可继续使用的判断
confidence: validated
```

## definition

收拢不是全文复述，而是把前文已经提供的事实、限制和选择关系重新显形。

## mechanism

只收拢会影响下一步的内容；先事实，再判断或行动，不引入新论据。

## realizations

教程每层一个回检句；访谈主持复述共识；文章段尾短句；正式材料用小结承接下一节。

## boundary_conditions

短文本不必每段总结；争议尚未解决时总结应保留分歧。

## overuse_risk

每段都‘综上所述’会形成路牌。

## repair_strategy

检查总结句能否删去；若删后下一段仍无损，改为隐性衔接。

## related_nodes

`restatement.md, closure.md, reader_anticipation.md`
