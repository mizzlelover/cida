# Uncertainty · 不确定性

```yaml
id: mech.uncertainty
name: 不确定性标注
function: 让证据边界和未知部分可见
confidence: validated
```

## definition

不确定性不是软弱，而是把事实、推断、假说和未知分开。

## mechanism

识别不确定性来自数据不足、概念争议、时间变化还是因果未知，再使用对应限定；限定后仍给当前可行动判断。

## realizations

‘截至目前’限定时间；‘这只能说明’限定证据；‘可能’只用于真实概率或假说。

## boundary_conditions

安全和责任事项不能用模糊词替代明确警示；已确定的事实不应过度保守。

## overuse_risk

每句都加限定词会降低信息密度。

## repair_strategy

为每个限定词写出它限制的对象，不能说明对象就删掉。
