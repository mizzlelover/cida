# Repair · 修复

```yaml
id: mech.repair
name: 表达修复
function: 在发现误解、说错、跳步或信息缺口时恢复共同理解
confidence: validated
```

## definition

修复是互动中对前一表达的补充、重说、限定或更正；书面文可预先吸收高概率修复。

## mechanism

识别故障类型（词义、事实、指代、推理、关系），选择最小修复动作并说明变化，不用新话术掩盖错误。

## realizations

口头用‘准确说是……’；文章用更精确的重述；访谈主持复述确认；研究报告保留修订记录。

## boundary_conditions

事实更正应明确，不用‘换个角度’掩盖前文错误；修复不能改写作者立场而不说明。

## overuse_risk

预防性解释太多会造成啰嗦。

## repair_strategy

把读者最可能误解的一个点提前修复，其余留给反馈回路。

- 状态：`validated`（2026-09-16 登记）。**本次升级不依赖新增证据**，而是按 §121 对既有来源结构做评估。
- 依据（§121 两条**均**满足）：**理论**＝Schegloff／Jefferson／Sacks 修复机制（国际经典）、Gumperz 语境化提示、何自然语用学、互动语言学方法、张-groundialog（≥3 个独立来源）；**表达者／语料样本**＝杨方 2024（修正标记）、尹海良 2009（标异-提醒）、李馨悦、谭方方 2024（标记迟疑／婉言缓冲）＋王辰访谈实录（ANNOTATED）三档修复实例。
- 跨来源比较——**"说明变化而非掩盖"是共同纪律，差异在强度与手段**：
  1. **概念级纠偏**（王辰访谈）：区分"新增确诊病例数"与"实际增加病例数"，防止统计口径被误读为疫情真相（强）；
  2. **显式标记纠偏**（王辰访谈）："需要指出的是…"（中）；
  3. **自我限定**（王辰访谈）："不是'至善之策'，却是可取之策、现实之策"（弱）；
  4. **修复的专用标记**（杨方 2024）："就是"用于修正，分元认知模式（自我监控）与互动模式（会话关注）；
  5. **修复的邻近形态**（李馨悦、谭方方 2024）："标记迟疑""婉言缓冲"——不直接更正而与对方面子相处；医疗语境下迟疑最凸显，故**修复强度受机构权力关系调节**；
  6. **边界参照**（尹海良 2009）："标异-提醒"提示听者认知偏差，但不等于更正；
  7. **提问侧修复**（路内×小白对谈，2026-09-17 补）：修正在**提问者一方且指向自己**——
     "我刚刚好像说错了……不是七十多天"；与 1–3 的"答方修复"合看，可得一条**成本序**：
     **修正指向自己 < 修正指向己方表述 < 修正指向对方立场**（后者最易变成对峙）。
- 边界：① **副语言层**（停顿、重音）未听校，本判定只覆盖结构与措辞层；② 本页 `repair_strategy` 的**预防性修复**（书面预先吸收高概率误读）**无口语语料直接验证**，属转译假定；③ 事实更正与立场改写不可混同（`boundary_conditions` 保持）。
