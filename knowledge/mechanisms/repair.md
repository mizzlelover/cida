# Repair · 修复

```yaml
id: mech.repair
name: 表达修复
function: 在发现误解、说错、跳步或信息缺口时恢复共同理解
confidence: contextual
```

## definition

修复是互动中对前一表达的补充、重说、限定或更正；书面文可预先吸收高概率修复。

## mechanism

识别故障类型（词义、事实、指代、推理、关系），选择最小修复动作并说明变化，不用新话术掩盖错误。

## realizations

口头用‘准确说是……’；文章用更精确的重述；访谈主持复述确认；研究报告保留修订记录。

## boundary_conditions

事实更正应明确，不用‘换个角度’掩盖前文错误；修复不能改写作者立场而不说明。

## overuse_risk

预防性解释太多会造成啰嗦。

## repair_strategy

把读者最可能误解的一个点提前修复，其余留给反馈回路。
