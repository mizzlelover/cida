# Argument Pivot · 论证转轴

```yaml
id: mech.argument_pivot
name: 论证转轴
function: 把材料、反例或疑问转成新的判断层级
confidence: contextual
```

## definition

转轴是文本从‘看见材料’转向‘改变理解’的瞬间。它不是简单的‘但是’，而是明确说明前一层为何不够以及下一层增加了什么。

## mechanism

材料→限制→重新命名→判断；转轴处保留必要的限定词，避免从一个案例跳到普遍结论。

## realizations

评论中由事实转判断；访谈中由回答追问条件；博客中由经验转原则；口播中用停顿和重音标记。

## boundary_conditions

没有新证据或新层级时不要制造转轴；单纯换话题应使用 topic shift。

## overuse_risk

每段都强行反转会使读者疲劳，形成‘其实真正的问题是’模板。

## repair_strategy

标出每个转折后的新增信息，新增信息为零时改为平实承接或删除。
