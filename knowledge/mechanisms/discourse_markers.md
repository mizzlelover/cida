# Discourse Markers · 话语标记系统

```yaml
id: mech.discourse_markers
name: 话语标记
function: 用语小词管理读者预期、衔接话轮、标记立场
confidence: validated
```

## definition

"其实""所以""但是""不过""问题是""换句话说""反过来看""说到底""也就是说"
"你会发现""更重要的是""这里有意思的是"——这些成分多数不承担命题意义，
但承担**话语管理**功能：预告转向、标记立场、召唤共同注意、降低理解成本。

## mechanism

话语标记是读者心智的**路标与缓冲**。完全删除它们，文本变得"干净但硌人"；
机械堆砌它们，文本变得"顺滑但空洞"。判断标准从来不是"这个词是不是AI高频词"，
而是四问：

```
1. 有没有真实话语功能？   —— 删掉后读者的理解路径是否受损？
2. 是否重复？            —— 同一段落两个"其实"是噪音
3. 是否可省略？          —— 语义关系已自明时，标记是冗余
4. 是否造成模板感？       —— 每段开头都是"更重要的是"，是模板不是功能
```

## 重点标记的功能谱（中文原生）

| 标记 | 核心功能 | 典型场景 |
|---|---|---|
| 其实 | 纠正预期/揭示真因 | 读者以为A，实际是B |
| 问题是 | 引入关键障碍 | 论证的转折点 |
| 换句话说 | 换层重述 | 抽象→具体的落地 |
| 说到底 | 收束到底层 | 峰值前置位 |
| 你会发现 | 联合注意 | 引导读者看一个事实（**不得自动删除**，见下） |
| 反过来看 | 视角反转 | 辩证推进 |

## Reader Address 专项

"你会发现""你想想""说到底你心里清楚"类**读者指向表达**：

- 承担 Joint Attention / Reader Anticipation 功能 → 保留；
- 只是每两段的机械召唤（"你可能会问……"×5）→ 删到只剩真正有功能的一两处。

## boundary_conditions

- 正式语域（公文、论文）话语标记应大幅收减，但不为零；
- 口播稿中话语标记密度天然高于文章，按媒介调参；
- 全文连接词过密（每句都有逻辑词）是 Over-signposting，见
  `../anti_patterns/template_transition.md`。

## repair_strategy

1. 标出全文所有话语标记，逐一过四问；
2. 无功能的删，有功能但重复的减到一次；
3. 删完后通读：如果文本变得"干而硬"，说明误删了功能标记，回补关键位置的。

## 语料校准（corpus-derived）

> 来源：`corpus/metadata/ruanyifeng_weekly_features.json`，n=82 期阮一峰周刊
> （2018-04 ~ 2026-08，state=READ 机器特征）。体裁限定：编辑体科技周刊。

- 话语标记密度中位数 1.78/千字（p25=1.49，p75=2.47）——**低但不归零**；
- 出现覆盖率（82 期中出现的期数）：但是 82、所以 66、其实 49、不过 44、
  也就是说 32、首先 29、问题是 27；
- 印证本页立场：功能标记在高质量文本中**持续存在但克制**——"但是"全覆盖
  说明转折标记是刚需；"更重要的是"仅 4/82 期出现，说明峰值标记是稀缺资源，
  滥用即模板（见 `../anti_patterns/template_transition.md`）。

## 口语语料校准（2026-09-16 补，**仅定性**）

> 来源：`corpus.interviews.bai-20200205-wangchen-cabin`（ANNOTATED，答问体，央视网官方实录）
> 与 `corpus.podcasts.ted-zhouyijun-2017`（ANNOTATED，演讲体，TED 官方中文稿）。
> **为什么只做定性**：语料按版权纪律不存全文，无法给出可复算的密度数值
> （书面体的 1.78/千字 见上节，可复算）。

- **答问体**的程序义标记以**纠偏类**为主："需要指出的是""需要看到""也就是说"——功能是
  把听者从常见误读里拽回来（功能谱中"其实／问题是"的口语变体）；"需要看到"一句同时
  承担纠偏与重述（见 `restatement.md`）。
- **演讲体**的程序义标记以**推进与换层类**为主："那么""但是""其实"——承担段落推进
  与视角转换，而非纠偏。
- 两例共同印证：**标记功能随语域迁移**——纠偏类在"对公众解释"的答问体高，推进类在
  单线叙事的演讲体高。这为 boundary_conditions「口播稿中话语标记密度天然高于文章，
  按媒介调参」补上语料侧依据；但**密度数值仍须在可存文本或听校条件下才能给出**，
  本页不据此改动任何数值。

## realizations

- **written**：以"但是／所以"承担刚需的转折与推论（82 期周刊中"但是"全覆盖），
  以"换句话说／说到底"承担换层与收束；峰值标记"更重要的是"仅 4/82 期出现
  ——**稀缺资源，滥用即模板**（`../anti_patterns/template_transition.md`）；
- **spoken**：同一功能由标记＋语调停顿共同承担，密度天然高于文章；
  **功能随语域迁移**——答问体以纠偏类为主（"需要指出的是""需要看到"），
  演讲体以推进与换层类为主（"那么""但是""其实"）；
- **formal**：大幅收减但不为零——保留"值得注意的是"这类承担真实预告的标记，
  删去纯填充；
- **informal**：标记更短更碎（"其实""就是"类），但每段的机械召唤
  （"你可能会问……"×5）属模板，不在本机制的保护范围。

## overuse_risk

话语标记密度过高会制造模板转场，全部删除又会损失预期管理；两者都必须回到功能判断。
