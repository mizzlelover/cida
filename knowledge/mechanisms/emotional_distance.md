# Emotional Distance · 情绪距离

```yaml
id: mech.emotional_distance
name: 情绪距离
function: 调整作者与读者、对象及事件之间的亲近和克制程度
confidence: contextual
```

## definition

情绪距离是表达对关切、冲突和脆弱性的接近方式。它既不是冷漠，也不是替读者规定情绪，
而是在事实、判断和共情之间保持可呼吸的空间。

## mechanism

识别处境→选择称谓和观察位置→给出判断→留下必要的情绪余地。距离随受众、权力关系和事件
严重度变化，不能用统一的热情或冷静覆盖全文。

## realizations

公共议题先承认受影响者的处境，再区分事实和责任；个人叙事保留具体感受，但把结论的强度
交给证据；正式文本用克制措辞避免煽情。

## boundary_conditions

悲伤、创伤和不对等关系中，不能用“平衡”抹平伤害；法律、医疗和政策说明仍须优先清楚和准确。

## overuse_risk

距离过近会变成煽情、替人发言或道德绑架，距离过远则让事实显得无关己身、读者不愿继续。

## repair_strategy

逐段检查作者是在描述、判断还是共情；为每种功能选择相称的语气，删去不能证明的情绪推断，
并保留当事人的限定和声音。
