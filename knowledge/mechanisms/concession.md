# Concession · 让步

```yaml
id: mech.concession
name: 让步
function: 承认对方成立部分以降低异议成本
```

## definition

让步把对方的有效观察留在论证里，再限定其适用范围；它不是礼貌套话，也不是把所有观点说成各有道理。

## mechanism

具体承认→指出边界→提出自己的判断。承认必须足够具体，否则读者感到操纵。

## realizations

‘这个担心确实存在，但它解释不了……’；主持先确认亮点再指出缺口；正式文本用条件句。

## boundary_conditions

事实错误、歧视性前提和高风险建议不需要形式让步。

## overuse_risk

连续让步会让作者失去判断，形成过度平衡。

## repair_strategy

只承认能被证据支持且与主张相关的部分，其余直接纠正并给依据。
