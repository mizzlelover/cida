# Topic Opening · 话题开场

```yaml
id: mech.topic_opening
name: 话题开场
function: 在最短路径内建立读者与问题的关系
confidence: validated
```

## definition

开场不是背景铺陈，而是让读者知道为什么此刻要继续读。有效开场给出具体场景、真实疑问、反常事实或有取舍的判断，并把后文的认知任务交代清楚。

## mechanism

先定位受众正在面对的处境，再给一个可追踪的问题；背景只有在影响判断时保留。开场速度由读者已有知识和反对成本共同决定。

## realizations

文章可用场景或判断；口播可用一个可听见的动作；正式文本可用问题和适用范围；社交平台需更快落到具体对象。

## boundary_conditions

历史回顾、研究报告等需要背景时，不强行删除背景；但背景必须服务于问题，不得以‘随着时代发展’替代定位。

## overuse_risk

每篇都用冲突、反常或悬念会形成模板开头，降低可信度。

## repair_strategy

删去不改变读者预期的寒暄和大背景，留下对象、问题、判断三者中至少两项。

- 跨来源比较——**"开场＝在最短路径内交付对象 + 问题（至少两项）"跨体裁收敛，差异在装置**：
  1. **共同起点反转**（周轶君，演讲体）：引《青花瓷》两句建立共同起点，随即以"其实青花根本就不是中国的东西"推翻常识，再用"不知道你们会作何感想"把认知落差**交给听众**；
  2. **个案并置双问**（《新闻1+1》20130730，电子媒体）：两起公共场合作案并置后连问"怎么样看待我们的治安所面临的挑战，怎么样看待这次的专项治理行动"，把挑战与治理**分开框定**；
  3. **标题承担一半**（《新闻1+1》20090616，评论体）："从'子弹'到'针头'的距离"为题，开场即落一项反直觉事实（"所有的死刑犯选择的都是注射死刑"）；
  4. **封闭设问**（《新闻1+1》20081009，评论体）：主持人直接向观察员设问"他到底跟中国有没有关系？"，把开放议题**一次收成可回答的封闭问题**；
  5. **固定分工四件套（第一集扩为六件）**（康辉·《平"语"近人》第一／三／十集，文化节目）：问好—自我介绍—欢迎现场—用典点题—引入解读人，**对象／问题／判断三项一次性交付**，且**三集同一骨架**（节目内稳定）；**第一集在点题段另有"报本集主题＋三连设问"两件**（第四十三批补）。
  五者共同落点＝本页 `repair_strategy`「留下对象、问题、判断三者中至少两项」；差异在**装置**（反转／双问／标题／设问／固定分工）与**交付主体**（讲者交给听众 vs 主持人设问给观察员 vs 节目固定分工）。
