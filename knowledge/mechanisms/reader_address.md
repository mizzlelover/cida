# Reader Address · 读者指向

```yaml
id: mech.reader_address
name: 读者指向
function: 把读者的注意力和疑问纳入表达设计
```

## definition

读者指向可以是直接称呼，也可以是顺着读者疑问安排信息；它不等于满篇‘你会发现’。

## mechanism

判断读者此刻的知识和阻力，在高概率疑问处给回应；称呼只在确有联合注意功能时出现。

## realizations

文章用一个自然问题；口播用‘你看’联合注意；知乎用反例回应；正式文本少用直接称呼。

## boundary_conditions

专业文本需尊重读者自主判断；不要用假共情或群体标签制造亲近。

## overuse_risk

每段设问、每段呼唤读者会显出模板感和讨好。

## repair_strategy

删掉低概率读者问题，只保留能改变阅读路径的一两处回应。
