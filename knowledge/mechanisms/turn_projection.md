# Turn Projection · 话轮预示

```yaml
id: mech.turn_projection
name: 话轮预示
function: 让听者预期下一步并降低跟随成本
confidence: validated
```

## definition

话轮预示是说话人在当前话轮中给出下一步的语义或韵律信号，文章可将其转译为有限的结构预告。

## mechanism

在转折、补充、例证或结论前提供最小提示，再立即兑现；提示不替代内容。

## realizations

口播用‘关键在于’和停顿；访谈用问题尾部锁定答复范围；文章用标题或语义桥。

## boundary_conditions

屏幕文本可回看，预示密度应低于实时听觉媒介；专家文本不需要逐步牵引。

## overuse_risk

每句话都预告会显出路牌堆叠。

## repair_strategy

只在读者无法自行预测且错误跟随成本高的位置添加预示。

- **访谈主持侧三形态（2026-09-17 第三十六批补，样本追加，不改变 `validated` 结论）**：王志·央视《面对面》
  专访易中天（`corpus.hosting.named.wangzhi-200608-yizhongtian`，ANNOTATED，**两页并查约 10,030 汉字**）——
  ①**最短追问**：嘉宾答"我根本不知道它在怎么变"后，主持人只问"怎么说？"（三字），**不给选项、不预设答案**；
  ②**嘉宾反问时换侧面**：嘉宾反问"这难道就是当今老百姓关心的事吗？不会吧"后，主持人改提
  "可能跟我们平常心目中的学者形象有很大的一个反差"——**不重复原问、换一个可回答的侧面**；
  ③**以"把回避命名"收束**：篇末"如果问一句为什么呢？"／"没有为什么。"／"为什么不呢？"／"为什么要呢？"…
  "但是你不愿意把答案告诉我们。"——**把对方的回避行为本身作为收束点并公开留白**。
  与本节既有"问尾并列两问锁定答复范围"合看，同一语域内共**四种投影装置**；
  边界：该页说话人标签作「记者：」（节目实录惯例），**原视频语气未听校**。

- 跨来源比较——**"位置可预示下一话轮功能"跨语域收敛**：
  1. 日常口语（欧芝同、谭方方 2024，120 例）：标记**不用于对话开始**；独立充当话轮 58%、话轮之首 35%、之中与末尾各 3.5%——**位置分布本身即投影信号**；
  2. 日常口语（尹海良 2009，"别说"）：常居话轮**开头或中间**，"引发-阐释"＝开新话轮并预告后续阐释；
  3. 书面化会话（王璇婷，"你还别说"）：开头 38%／中间 62%，两种位置各担开启与延续；
  4. 机构会话（李馨悦、谭方方 2024，医患）：形式连贯三式＝**引发／转接／占据**话轮；
  5. 访谈（王辰，ANNOTATED）：**问尾并列两问**锁定答复范围（"初衷是什么？能发挥多大作用？"），受访者逐项兑现；
  6. 访谈主持侧（王志，ANNOTATED，2026-09-17 补）：三种装置——**最短追问**（"怎么说？"三字索取展开）、
     **嘉宾反问时换侧面**、**把回避命名后不再逼问**（"但是你不愿意把答案告诉我们"）。
  六者共同落点＝本页 definition「在当前话轮给出下一步信号」；差异在**投影装置**（话轮操作语 vs 问尾与追问结构）
  与**作用对象**（听者／受访者／被点评者 vs 读者）。
- 边界：① **副语言层**（停顿、重音、语速）未听校，本判定**只覆盖结构与措辞层**；② 本页 `realizations` 所述**书面文章的"标题／语义桥"投影属转译假定**，尚无书面语料直接验证；③ `overuse_risk`（路牌堆叠）与 `boundary_conditions`（屏幕文本可回看）仍为经验判断，未经对照实验。
