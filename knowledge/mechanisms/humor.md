# Humor · 幽默

```yaml
id: mech.humor
name: 幽默
function: 以低威胁的错位、轻松或自嘲降低防御并打开理解入口
confidence: validated
```

## definition

幽默是让读者在不被强迫接受结论的情况下，看见一个关系、尺度或惯性的错位。
它服务于理解和关系，不是给文本贴上轻浮的表情。

## mechanism

共同处境→可识别的错位→短暂松弛→回到事实或判断。笑点不能替代证据，也不能把受影响者
变成被嘲弄的对象。

## realizations

主持或访谈中可用自嘲、生活化比喻和轻微反差为追问降压；文章中只在复杂概念已有清晰解释后
使用一次轻量错位，随后回到主线。

## boundary_conditions

悲剧、权力不对等、医疗法律和未核实事实场景应优先保护当事人；面对陌生受众时先判断共同背景。

## overuse_risk

连续抖机灵会稀释判断，把严肃问题娱乐化，或让作者显得在逃避立场。

## repair_strategy

删除不能带来理解或关系改善的笑点；保留后检查笑点之后是否仍有事实、限定或行动落点。

## 跨来源验证（§121）

- 状态：`validated`（2026-09-16 登记）。初判为 `contextual` 时的缺口是"仅 1 位表达者"，**当日补足第 2 位后升级**。
- 依据（§121 二选一取后者）：**理论**＝访谈主持、Tannen 会话风格、Goffman 互动仪式、Aristotle《修辞学》（≥3 个独立来源）；**语料样本**＝刘未鹏（博客体）、陈晓卿（演讲体），**2 位表达者、2 语域**。
- 跨来源比较——**"错位指向作者自己"跨语域收敛，差异在错位对象**：
  1. **自嘲式降压**（刘未鹏，博客体）："土鳖也有土鳖的幸福:P"把作者与读者放在同一"土鳖"位置上；"高爷爷真不愧是姓高的，囧rz.."为字形玩笑——**松弛后仍回到判断**；
  2. **自嘲开场 + 比喻自设反驳**（陈晓卿，演讲体）：先自嘲"不配拥有姓名"，再用"章鱼／螳螂／黑寡妇蜘蛛"当场检视自己的比喻。
  两者共同落点＝本页 mechanism「共同处境 → 可识别的错位 → 短暂松弛 → 回到事实或判断」，以及 definition「服务于理解和关系，不是给文本贴上轻浮的表情」；差异在**错位对象**（作者身份／作者的比喻）。**两例的错位都落在作者自身，不落在他人身上**——这与 `boundary_conditions` 同向。
- 边界：① 两例均为 `scripted`／编辑后文本，**即兴幽默未覆盖**；② 权力不对等场景**仍无样本**——现有正例只能说明"可以不做笑点"，**不等于已证明各类场合的处理方式**；③ **副语言层**（语气、节奏、观众反应）未听校。
