# Humor · 幽默

```yaml
id: mech.humor
name: 幽默
function: 以低威胁的错位、轻松或自嘲降低防御并打开理解入口
confidence: contextual
```

## definition

幽默是让读者在不被强迫接受结论的情况下，看见一个关系、尺度或惯性的错位。
它服务于理解和关系，不是给文本贴上轻浮的表情。

## mechanism

共同处境→可识别的错位→短暂松弛→回到事实或判断。笑点不能替代证据，也不能把受影响者
变成被嘲弄的对象。

## realizations

主持或访谈中可用自嘲、生活化比喻和轻微反差为追问降压；文章中只在复杂概念已有清晰解释后
使用一次轻量错位，随后回到主线。

## boundary_conditions

悲剧、权力不对等、医疗法律和未核实事实场景应优先保护当事人；面对陌生受众时先判断共同背景。

## overuse_risk

连续抖机灵会稀释判断，把严肃问题娱乐化，或让作者显得在逃避立场。

## repair_strategy

删除不能带来理解或关系改善的笑点；保留后检查笑点之后是否仍有事实、限定或行动落点。
