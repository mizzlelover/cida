# Empathy · 共情对齐

```yaml
id: mech.empathy
name: 共情对齐
function: 承认读者或对话对象的处境而不牺牲判断
confidence: contextual
```

## definition

共情是准确描述对方处境、成本和担心，再决定是否推进异议；不是廉价安慰或假装同意。

## mechanism

命名处境→承认合理成本→区分事实与解释→给下一步；共情对象应具体。

## realizations

访谈先复述经历再追问；服务文本先承认办理成本；文章在反驳前说明读者为何会这样想。

## boundary_conditions

涉及伤害、歧视和权力不对等时，共情不能替代责任追究。

## overuse_risk

把每个判断都包装成安慰，会产生知识服务腔。

## repair_strategy

删除泛泛的‘我理解你’，改为一个可核对的处境事实。
