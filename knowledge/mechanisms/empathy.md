# Empathy · 共情对齐

```yaml
id: mech.empathy
name: 共情对齐
function: 承认读者或对话对象的处境而不牺牲判断
confidence: validated
```

## definition

共情是准确描述对方处境、成本和担心，再决定是否推进异议；不是廉价安慰或假装同意。

## mechanism

命名处境→承认合理成本→区分事实与解释→给下一步；共情对象应具体。

## realizations

访谈先复述经历再追问；服务文本先承认办理成本；文章在反驳前说明读者为何会这样想。

## boundary_conditions

涉及伤害、歧视和权力不对等时，共情不能替代责任追究。

## overuse_risk

把每个判断都包装成安慰，会产生知识服务腔。

## repair_strategy

删除泛泛的‘我理解你’，改为一个可核对的处境事实。

- **评论体补充样本（2026-09-16）**：《新闻1+1》20090616（`corpus.commentary.bai-20090616-death-penalty`，ANNOTATED，央视网实录直读）——主持人在第三轮**主动切换到受害者家属视角**发问（"当他一下子杀害了 8 个人的时候，当我们站在受害人家属的角度去想……"），观察员先承认"我们当然理解所有受害人家属那样的一种心情，其实枪毙一次可能都不解恨"，再回到判断（"对他最大的惩罚就是让他失去生命，那么这一点法律已经给你公正"）。这是 `empathy` 与 `concession` 的组合：**承认对方的情绪为真，同时不放弃法律判断**，正合本节「不牺牲判断」。

- 跨来源比较——**"承认处境而不牺牲判断"跨语域收敛，差异在共情对象与先后顺序**：
  1. **命名具体处境**（王辰，答问体）：不停留于"理解大家担心"，而先命名处境（轻症患者需强度不大的治疗、需与家庭社会隔离），再给判断"这不是至善之策，却是可取之策"；
  2. **理解与认同分开**（周轶君，演讲体）：与英国朋友激烈争论后"并没有跟这个朋友绝交，我反而是试图去理解他为什么这么来看"——**先追究（"那不是抢来的吗"）再理解**，是 `boundary_conditions`「共情不能替代责任追究」的正面用法；
  3. **情绪为真 + 判断不弃**（评论体）：主持人主动切到受害者家属视角发问，观察员先认"枪毙一次可能都不解恨"，再回到"对他最大的惩罚就是让他失去生命，那么这一点法律已经给你公正"。
  三者共同落点＝本页 definition「准确描述对方处境、成本和担心，再决定是否推进异议」；差异在**共情对象**（公众担忧／异国朋友／受害者家属）与**顺序**（处境先行／追究先行／情绪先行）。
- 边界：① 三例**副语言层**（语气、停顿）未听校；② `overuse_risk`（把每个判断都包装成安慰→知识服务腔）**未做真实负例抽样**；③ **无真实伤害／歧视场景样本**，`boundary_conditions` 仅经例 2 的"反面用法"间接触及。
