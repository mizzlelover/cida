# Emphasis · 强调

```yaml
id: mech.emphasis
name: 强调
function: 把读者必须记住的部分从信息平面托起
confidence: validated
```

## definition

强调通过位置、重复、短句、标点或语音重音聚焦重点，不等于提高所有句子的音量。

## mechanism

先确定主判断，再用一种形式强化；强化之后回到普通表达，形成峰值与平地。

## realizations

独立短句、句末落点、主持复述、演讲重音、段首或段尾位置。

## boundary_conditions

数据和风险信息的强调要服从事实等级，不能靠修辞制造确定性。

## overuse_risk

整篇加粗、排比或独立成段会让重点失去稀缺性。

## repair_strategy

按 quote-worthiness filter 只留少数峰值，其余改为平实句。
