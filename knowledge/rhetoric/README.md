# 汉语修辞学要点（rhetoric）

辞达的修辞观：**修辞必须承担意义**（Rhetoric is not Decoration）。
修辞不是文采的装饰层，而是意义的最优形式。

## 核心命题

1. **题旨情境第一**：修辞的评判标准是它是否适应"题旨"
   （要表达的内容）与"情境"（读者、场合、媒介）。脱离题旨情境谈辞格，
   是本末倒置。
2. **常格与变格**：规范表达是常格，有意偏离是变格；
   变格的价值来自对常格的张力。全程变格 = 没有变格。
3. **表达亮点的稀缺性**：
   金句本质是稀缺的。见 `../mechanisms/rhetorical_peak.md`。
4. **情采相称**：
   修辞密度必须与真实内容相称。
5. **清楚、合宜且自然**：文体选择随主题、受众与媒介变化，口头与书面不能用同一把尺。

## 重点辞格的功能定位（节选）

| 辞格 | 功能 | 风险 |
|---|---|---|
| 比喻 | 理解/记忆/情感 | 装饰化、陈喻 → `../mechanisms/metaphor_analogy.md` |
| 排比 | 语势、列举的整饬 | 领导讲话腔、为对称而对称 |
| 设问 | 引导注意、推进话题 | Fake Hook、Over-questioning |
| 反问 | 强化判断 | 咄咄逼人、密度失控 |
| 对偶 | 收束与记忆点 | 形式主义 |
| 反复 | 强调 | 语义重复 |
| 转折 | 论证推进的主力 | 假转折（"然而"后无转折） |

## 与机制库的关系

判断辞格是否合适时，要看它在当前文本中承担什么功能、适用于什么语境，
以及是否造成滥用。
