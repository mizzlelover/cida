# 互动语言学与会话分析要点（conversation）

这是辞达最核心的知识支柱之一：**文章借鉴会话机制，但不照搬聊天记录**
（Conversation-informed, not Spoken-like）。

## 会话机制 → 写作机制的转写表

| 会话机制 | 会话中的表现 | 写作中的对应物 |
|---|---|---|
| Turn-taking 话轮转换 | 自然的交接 | 段落与话题的自然转换 |
| Repair 修复 | 说错了现场修正 | 预判读者的误读并提前澄清 |
| Sequence 序列 | 问—答、提议—回应 | 设问—解答、主张—论证的段落组织 |
| Response 回应 | 对他人话语的回应 | 对想象读者疑问的回应（Reader Anticipation） |
| Alignment 对齐 | "对对对""就是" | 与读者共识的确认（"这一点我们都看到了"） |
| Stance 立场 | 语气词、评价 | 立场系统（stance_system.md） |
| Empathy 共情 | 情绪回应 | 对读者处境的体认 |
| Grounding 共同基础 | 确认互相理解 | 关键节点的回检与收拢 |
| Topic Shift/Return | "说到这个""话说回来" | 话题转换与回环的信号设计 |

## 语气词与话语标记

"吧""呢""啊""其实""就是""你知道"——这些成分是汉语会话的精密仪器，
各有互动功能。写作中：**功能保留，形式折算**——语气词的互动功能
（缓和、召唤、确认）转写为措辞与句式，而不是把"呢吧啊"搬进文章。

## 边界

- 转写的目标是**机制**，不是口头形式；
- Chat-log Fragmentation（聊天记录式碎片化）是失败模式，见
  `../anti_patterns/README.md`；
- Podcast Rambling（播客式散漫）同理：口语的迂回在文中要折算为结构。
