# 汉语语用学要点（pragmatics）

辞达的语用观：**字面之下还有一层真实的交际**。
言外之意、礼貌、立场、预设、语境——这些是"对话感"的微观零件。

## 核心命题

1. **意义 ≠ 字面。** "这个方案很有意思"可能是赞美也可能是婉拒——
   语用判断依赖语境。重写文本时，必须检查关键句的言外之意是否会被误读。
2. **礼貌与面子。** 表达异议、拒绝、批评时，措辞管理的是对方的面子。
   见 `../mechanisms/disagreement_without_distance.md`。
3. **立场（Stance）无处不在。** 即使"客观陈述"也在通过选材与措辞表态。
   见 `../mechanisms/stance_system.md`。
4. **预设是高效的，也是危险的。** 预设读者没有的知识 = 把读者关在门外；
   预设读者已有的立场 = 冒犯异见者。
5. **合作原则的中文实现。** 适量、真实、相关、清楚——Grice 四准则在中文
   语境的具体表现有自己的偏好（如"含蓄"的合法区间比英文宽）。

## 应用场景

- 诊断时：找出"字面没错、语用翻车"的句子（预设错误、面子威胁、立场模糊）；
- 重写时：限定与hedging的校准——智识诚实 ≠ 机械加"可能"；
- 平台适配时：不同平台的面子文化不同（知乎的论证礼仪 vs 小红书的社群礼仪）。
