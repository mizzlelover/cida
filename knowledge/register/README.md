# 汉语语体研究要点（register）

辞达的语体观：**语体是连续空间，不存在"越口语越好"**。
Register Adaptation 的目标是按受众与场合落在正确的位置。

## 语体的对立轴

```
正式 ←→ 非正式      口语 ←→ 书面
典雅 ←→ 通俗        专业 ←→ 日常
公共 ←→ 私人        传播 ←→ 学术
```

冯胜利语体语法的核心贡献：语体差异不只是"用词文雅与否"，
而有**语法层面的系统性**（如正式体的音步、构词、句法选择）。
对辞达的意义：语域移动（Register Shift）是系统工程，
不是把"的"改成"之"、把"但是"改成"然而"的表面替换。

## 关键判断

1. **语域错配是病，语域本身不是病。** 公文腔写进公众号是错，
   公文腔出现在公文里是对。
2. **中间语域是真实存在的目标**——辞达的默认 Profile 落在
   正式度 4–5、口语感 6–7 的中间地带，它有自己的完整性与尊严，
   不是"两边都不像"的妥协。
3. **语域移动有成本。** 正式→自然：拆名词化、降抽象、补读者视角；
   自然→正式：术语归位、程式归位。移动时牺牲的准确性必须赎回。

## 与评测的关系

Chinese Idiomaticity（中文地道度）是一级评测项：检查过度名词化、
长定语、被动堆积、西式从句、虚浮抽象词、翻译腔——但**禁止纯粹复古化**。
目标是现代中文，不是古文腔。
