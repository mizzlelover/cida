# 中文写作与新闻评论传统要点（writing）

## 写作与评论

文章要写给具体读者看。读者意识决定信息从哪里开始、怎样展开，以及哪些背景不可省略。

评论写作强调观点、论证、判断与效率，是训练清晰表达的一种方式。

## 核心命题

1. **文章是交际行为。** 书面表达可以像认真交谈一样清楚，但不等于照搬闲聊。
2. **修改是写作的一部分。** 删繁就简不是损失，而是让重要内容更清楚。
3. **判断是评论的骨头。** 文章的价值在观点与论证，不在辞藻堆叠。
4. **中文表达要自然。** 留意抽象名词堆叠、被动句滥用、长定语和翻译腔。
5. **技巧服务于表达，不展示自身。** 每种写法都应帮助意思更好地送达。
