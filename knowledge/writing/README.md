# 中文写作与新闻评论传统要点（writing）

## 两条传统

**文章学传统**（叶圣陶、夏丏尊、王鼎钧、张中行）：
文章是写给别人看的——读者意识是这一传统的心脏。《文心》用对话讲文章作法，
《作文十九问》用问答体教写作：这些文本本身就是"对话型表达"的早期样本。

**新闻评论传统**（马少华、丁法章、刘明华）：
观点、论证、判断、效率。评论是"有立场的清晰"的极端训练场。

## 核心命题

1. **文章是交际行为。** 叶圣陶："写文章就是说话，但不是闲聊。"——
   这是 Conversation-informed Writing 的中文原生源头之一。
2. **修改是写作的一部分。** 《文章例话》的示范：好文章是改出来的，
   删繁就简不是损失，是提纯。
3. **判断是评论的骨头。** 马少华：评论的价值在观点与论证，
   不在辞藻——对应辞达的 Judgment Quality 与内容优先原则。
4. **警惕英式中文。** 余光中：抽象名词堆叠、被动滥用、长定语是
   现代中文的慢性病——Chinese Idiomaticity 评测的经典依据。
5. **技巧服务于表达，不展示自身。** 王鼎钧《作文七巧》的技巧体系
   全部是"为了把意思更好地送达"。

## 与机制库的关系

本目录的结论经"功能化"后进入机制节点（如 Compression、Explanation、
Closure）；不得把任何写作口诀直接当作 Universal Rule——一律先作为假说验证，
再决定是否进入机制节点。
