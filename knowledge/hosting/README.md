# 播音主持与即兴表达要点（hosting）

辞达从播音主持传统中抽取的是**能力**，不是"主持腔"。

## 抽取清单（能力 → 写作转化）

```
即兴成篇     → 无提纲状态下组织完整论述的能力 → 文章的自然结构力
即兴评述     → 对眼前事物快速形成判断         → Judgment Formation
即兴总结     → 把散乱谈话收束成一句话         → Compression + Closure
话题推进     → 冷场时开话题、跑偏时收回来     → Topic Progression
追问         → 逼近具体的连续追问             → Reader Anticipation 的访谈原型
承接         → 接住对方的话并往前带           → 段落的衔接意识
收束         → 在恰好的地方结束               → Ending 的位置感
```

## 主持人语料的研究方向（候选假说，待语料验证）

> **诚信声明（§119–121）**：下表中的能力指向来自项目任务书的实践者假设，
> **尚未经过语料验证**。任何人名的能力结论只有在满足以下条件后才升级为
> Candidate Mechanism：第一阶段实际取得 ≥10 个有效长样本或 ≥60 分钟有效
> 现场表达；模式多次出现、跨主题出现、功能一致；并经 ≥3 个不同来源或
> 「理论 + ≥2 位表达者」交叉验证。在此之前一律标记为
> `speaker-specific / unverified`，禁止根据名气推断语言特征。

| 白岩松 | 《新闻1+1》 | Commentary Compression、Problem Framing | 不模仿其语言指纹 |
