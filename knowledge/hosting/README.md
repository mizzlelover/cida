# 播音主持与即兴表达要点（hosting）

辞达从播音主持传统中抽取的是**能力**，不是"主持腔"。

## 抽取清单（能力 → 写作转化）

```
即兴成篇     → 无提纲状态下组织完整论述的能力 → 文章的自然结构力
即兴评述     → 对眼前事物快速形成判断         → Judgment Formation
即兴总结     → 把散乱谈话收束成一句话         → Compression + Closure
话题推进     → 冷场时开话题、跑偏时收回来     → Topic Progression
追问         → 逼近具体的连续追问             → Reader Anticipation 的访谈原型
承接         → 接住对方的话并往前带           → 段落的衔接意识
收束         → 在恰好的地方结束               → Ending 的位置感
```

## 主持人语料的研究方向（候选假说，待语料验证）

> **诚信声明（§119–121）**：下表中的能力指向来自项目任务书的实践者假设，
> **尚未经过语料验证**。任何人名的能力结论只有在满足以下条件后才升级为
> Candidate Mechanism：第一阶段实际取得 ≥10 个有效长样本或 ≥60 分钟有效
> 现场表达；模式多次出现、跨主题出现、功能一致；并经 ≥3 个不同来源或
> 「理论 + ≥2 位表达者」交叉验证。在此之前一律标记为
> `speaker-specific / unverified`，禁止根据名气推断语言特征。

| 人物 | 主要语料 | 待验证的假设方向 | 警惕 |
|---|---|---|---|
| 白岩松 | 《新闻1+1》 | Commentary Compression、Problem Framing | 不模仿其语言指纹 |
| 董卿 | 《主持人大赛》点评 | Abstract & Elevate、温和纠偏 | 不复制其修辞习惯 |
| 康辉 | 新闻播报与点评 | Precision、正式/日常切换 | 播音腔不等于书面清晰 |
| 撒贝宁 | 现场互动 | Adaptive Orality、复杂通俗化 | 幽默的语境依赖极强 |
| 窦文涛 | 《锵锵三人行》 | Conversational Flow、Topic Return | 散漫不是松散的自然 |
| 杨澜 | 知识型访谈 | Structured Inquiry、问题链 | — |
| 王志 | 调查访谈 | Precision Questioning | 逼问姿态不入文 |
| 陈鲁豫 | 访谈 | Question Economy、Short Follow-up | 整体风格不作模板 |
| 柴静 | 调查报道与演讲 | Humanized Inquiry、Concrete-to-Abstract | — |
| 董倩 | 公共议题访谈 | Public Issue Questioning | — |
| 敬一丹 | 人物访谈与新闻 | Narrative Compression、Evidence Boundary | 经验叙述需回到来源 |
| 鲁健 | 重大直播与访谈 | Audience Calibration、Register Adaptation | 直播资源不等于写作规则 |
| 崔永元 | 民生节目与口述历史 | Relational Entry、Public Reframing | 轻松暖场需看议题风险 |
| 水均益 | 国际访谈 | Restrained Authority、Question Economy | 亲历经验不能替代档案 |
| 倪萍 | 人物访谈 | Empathic Inquiry、Story Entry | 情绪入口不替代事实 |
| 周涛 | 访谈与主持 | Prepared-to-Spontaneous Shift | 舞台语境需单独标注 |
| 何炅 | 娱乐访谈 | Rapport Building、Topic Return | 亲近感不等于放弃边界 |
| 邹韵 | 主持人大赛 | Commentary Compression、Task Framing | 竞赛点评有时限约束 |

**铁律**：Speaker → Observed Ability → Discourse Mechanism →
Cross-speaker Comparison → Transferable Pattern。
任何一步不得跳过；禁止出现"XX 风"式 Style Preset。
