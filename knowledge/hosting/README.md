# 现场表达与主持能力（hosting）

现场表达中的组织、追问、承接和收束，也能帮助书面表达更清楚、更有交流感。

## 写作中的对应动作

| 写作需要 | 表达动作 |
|---|---|
| 组织观点 | 把零散信息归到清楚的主张和论证中 |
| 形成判断 | 说清楚判断对象、理由和适用范围 |
| 推进话题 | 回应上下文中的问题，避免突然转向 |
| 追问细节 | 找出读者可能不理解或不相信的地方 |
| 收束内容 | 在合适位置落到判断、行动或问题 |

## 使用边界

- 按任务查阅 `knowledge/mechanisms/GRAPH.md` 中的 `audience_design`、`question_framing`、`repair`、`closure`、`topic_return` 与 `self_positioning`。

借鉴现场表达时只采用有助于当前任务的动作；不模仿具体主持人的个人风格。
